# 💬 DebateMate — AI Debate Assistant

**Think · Discuss · Grow**

DebateMate is an AI-powered debate assistant designed to encourage critical thinking, explore different perspectives, and help users develop logical arguments through interactive discussions.

## ✨ Features

- 🤖 AI-powered conversational debates
- 🧠 Critical thinking and logical reasoning
- 💡 Exploration of different viewpoints
- 💬 Interactive discussions on various topics

## 🛠️ Built With

- Python
- Fetch.ai uAgents
- OpenAI API

## 🚀 Getting Started

### Prerequisites

- Python 3 installed
- Git installed
- Required API keys

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd DebateMate
   ```

3. Install the required packages according to your project's dependencies.

4. Configure your API keys as environment variables.

5. Run your agent using the appropriate Python script.
